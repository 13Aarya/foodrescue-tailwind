# FoodRescue 🍱

FoodRescue is a responsive web platform designed to reduce food wastage
by connecting food donors, rescuers, and NGOs.

## Features

- Responsive Tailwind CSS interface
- Dark / Light mode
- Food Rescue Radar
- Live Rescue Map simulation
- Food freshness countdown
- Donor / Rescuer / NGO role selection
- Impact statistics
- Rescue streak
- Food reservation interaction
- Notifications and toast messages
- Responsive mobile navigation
- Tailwind Typography plugin

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome
- Tailwind Typography Plugin

## Project Structure

index.html – Main webpage containing the complete FoodRescue interface.

## Purpose

The project aims to provide a user-friendly interface for connecting
surplus food with people and organizations that can redistribute it.
